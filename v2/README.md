# Лендинг-портфолио: Радикал (UI/UX, Графика, Python, gLua, Web)

Современный, адаптивный и минималистичный персональный сайт-портфолио в темной стилистике с эффектами Glassmorphism и неонового свечения.

## 🚀 Быстрый запуск

Сайт работает на чистом стеке без сборщиков и внешних тяжелых зависимостей.

1. **Простой запуск**: просто откройте `index.html` в любом браузере (двойной клик по файлу).
2. **Локальный веб-сервер**:
   ```bash
   python -m http.server 8000
   ```
   и откройте [http://localhost:8000](http://localhost:8000).

## 💎 Особенности и структура

- **Hero-блок**: статус доступности к заказам, информация («Сочи, 18 лет 🌴»), кнопки действия и быстрые ссылки на соцсети (Telegram, GitHub, Discord, VK).
- **Кнопка «Заказать дизайн»**: размещена в хедере, hero-секции, карточках услуг, кейсах, CTA-баннере и футере. Ведёт напрямую в Telegram: [https://t.me/m/SK5JK1LAMzky](https://t.me/m/SK5JK1LAMzky).
- **Интерактивный фильтр кейсов**: переключение между категориями («Все», «UI/UX Дизайн», «Графика & Брендинг», «Разработка (Python / gLua)»).
- **Стек технологий**: структурированные бейджи с индикаторами направлений (Дизайн, Код, Принципы работы).
- **Копирование контактов**: клик по тегу Discord или кнопке «Скопировать ссылку» копирует данные в буфер обмена и вызывает всплывающее уведомление (Toast).
- **Эстетика и эффекты**:
  - Плавное следование неонового свечения за курсором мыши (на ПК).
  - Эффект матового стекла (`backdrop-filter: blur(16px)`).
  - Адаптивное бургер-меню для мобильных устройств и планшетов.
  - Поддержка `prefers-reduced-motion` для людей с чувствительностью к анимациям.
