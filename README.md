# Лендинг-портфолио: Радикал (UI/UX, Графика, Python, gLua, Web)

Минималистичный и футуристичный персональный сайт-портфолио с интерактивной 3D-графикой (Three.js), эффектами Glassmorphism, 3D-наклоном карточек, гибким прайс-листом (Базовый, Про, Премиум) и централизованным конфигурационным файлом `config.js`.

---

## ⚡ Быстрый старт

Сайт работает на чистом стеке (HTML5 + Modern CSS + Vanilla JS + Three.js CDN) без сборщиков и сложных зависимостей:
1. **Открыть в браузере**: просто дважды кликните по файлу [`index.html`](file:///c:/Users/rad1kal/Documents/antigravity/agitated-hertz/index.html).
2. **Локальный веб-сервер**:
   ```bash
   python -m http.server 8000
   ```
   и откройте [http://localhost:8000](http://localhost:8000).

## 💎 Реализованные решения:

1. **Интерактивная 3D-голограмма (Three.js)**:
   - В Hero-секции размещена 3D модель (кибернетический Torus Knot со светящимся внутренним икосаэдром, вращающимися орбитальными кольцами и облаком из 90 неоновых частиц).
   - Реагирует на движение мыши и поддерживает вращение перетаскиванием (drag to rotate).
   - Учитывает `prefers-reduced-motion` для доступности.

2. **3D-наклон карточек (Tilt effect)**:
   - Карточки услуг, тарифов и портфолио плавно наклоняются в трехмерном пространстве (`perspective(1000px)`) вслед за положением курсора.

3. **Разные кнопки для разных типов заказов**:
   - В шапке, Hero (бейдж-пилюли), карточках услуг и кейсах портфолио кнопки ведут на персонализированные Telegram-ссылки под конкретную задачу.
   - Цветные индикаторы для каждого направления (фиолетовый — UI/UX, розовый — Графика, синий — Python, индиго — gLua, изумрудный — Под ключ).

4. **Прайс-лист с 3 тарифами (Базовый, Про, Премиум)**:
   - Интерактивный переключатель направлений (UI/UX Дизайн, Графика & Брендинг, Python & Боты, gLua GMod, Сайт под ключ).
   - Динамический вывод 3 тарифов с ценами, сроками, бейджами («🔥 Выбор клиентов», «⭐»), списком преимуществ и кнопками заказа.
   - Блок индивидуальной консультации.

5. **Остальной функционал**:
   - Следование световой ауры за курсором.
   - Фильтр портфолио (Все, UI/UX, Графика, Разработка).
   - Интерактивный терминал с кодом `radikal_core.py`.
   - Копирование Discord тега `rad1kal` с Toast-уведомлением.
   - Полная адаптивность (Desktop, Tablet, Mobile) с бургер-меню.
